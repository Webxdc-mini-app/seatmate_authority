# 席待ち SEATMATE

Delta Chatのミニアプリ（webxdc）として使う、店舗向けの共有受付・席待ち管理アプリです。アプリ内の名称は「席まち」です。

入口の端末でお客様を受け付け、スタッフの端末で案内・退店を操作します。受付番号、人数、待ち順、席番号、店舗設定を、スタッフ専用グループ内で共有できます。

**現在の配布版：1.1.1**  
README更新日：2026年10月18日

## 主な機能

- 名前・ニックネームと人数による受付、受付番号の発行。
- 人数分の空き席が揃った組への、受付順での席割り当て。
- スタッフ操作による、入口画面への席案内の表示。
- 退店・受付取消と、次の組への席の割り当て。
- 店舗名、総席数、入口の歓迎メッセージ、予想待ち時間の共有設定。
- スタッフ画面への切替タップ回数の変更と、パスワードによる簡易ロック。
- 入口端末の交代、旧入口が使えない場合の復旧。
- 共通形式のJSONバックアップによる保存・復元と、対応する別バージョンへの移行。

## 共有の仕組み

| 端末 | 担当 |
| --- | --- |
| 入口・確定端末 | 受付を登録し、スタッフから届く案内・退店・設定変更を確定します。1台を指定し、アプリを開いたまま運用します。 |
| スタッフ端末 | 受付一覧を確認し、案内・退店・設定変更を要求します。結果は入口で確定してから共有されます。 |

**全端末で、同じグループに送った「同じ1件のメッセージ」に添付されたアプリを開いてください。** 同じ名前のファイルでも、端末ごとに別々に送信したものは別台帳になります。

通信状況により同期が遅れる場合があります。「共有履歴を反映済み」という表示は、その端末で受信した履歴を反映したという意味であり、全端末への配達完了を示すものではありません。

## 初めて使うとき

1. 店舗管理者とスタッフだけのDelta Chatグループを用意します。
2. `outputs/seatmate_authority_1.1.1.xdc` を、そのグループへ**1回だけ**送信します。
3. 全端末で、その同じメッセージに添付されたアプリを開きます。
4. 入口にする端末で、右上の「スタッフ端末」を続けて3回押します。各タップの間隔は1秒未満にしてください。
5. 初期パスワード `secret` を入力し、「ロック解除」を押します。
6. 「この端末を入口の確定端末に設定」を押します。最初の指定は1台だけで行います。
7. スタッフ画面の「店舗設定」で店舗名・総席数を保存し、スタッフ用パスワードも変更します。
8. 「入口画面へ」で戻ります。他の端末はスタッフログインして使います。
9. テスト受付が別の端末にも表示され、案内・退店が共有されることを確認します。

バックアップを読み込んで移行する場合は、**入口を指定する前に**読み込んでください。

## 日常の操作

### 受付と案内

1. 入口端末で名前（任意）と人数を入力し、「受付する」を押します。
2. 受付番号を確認し、お客様にスタッフの案内を待っていただきます。
3. スタッフ端末で対象の受付番号・人数・席番号を確認します。
4. 「席割当済み・案内前」の組の「案内を表示」を押します。
5. 入口画面に案内が出たことを確認し、お客様をご案内します。
6. 案内を確認したら、入口で「案内を確認したので閉じる」を押します。この操作では退店になりません。

人数分の空き席が揃わない間は順番待ちになります。席の割り当てと入口への案内表示は別の段階です。受付直後の番号表示は約20秒で消えますが、受付自体は残ります。

### 退店と受付取消

スタッフ端末で対象を確認し、「退店・席を空ける」または「受付を取り消す」を押します。確認画面の内容が正しければ「この内容で実行」を押してください。

入口で確定すると受付が一覧から消えます。待っている組に席が割り当てられたら、スタッフが改めて「案内を表示」を押します。退店・取消を元に戻す専用機能はありません。

## 設定を変更する

変更は入口端末で確定した後に全端末へ共有されます。入口端末ではアプリを開いたままにしてください。

| 設定 | 操作・範囲 |
| --- | --- |
| 店舗名・総席数 | 「店舗設定」で変更し、「設定を保存」。総席数は1〜200席。利用中の席番号より少ない席数には減らせません。 |
| スタッフ切替のタップ回数 | 「店舗設定」の「スタッフ画面へ切り替えるタップ回数」で1〜10回から選んで保存。初期値は3回です。 |
| スタッフ用パスワード | 現在のパスワードと6文字以上の新しいパスワードを入力。確定後は新しいパスワードで再ログインします。 |
| 予想待ち時間 | 1〜999分を手動設定。満席または順番待ちがあるときに表示します。空欄で保存すると未設定になります。 |
| 歓迎メッセージ | 160文字以内。改行も使用できます。空欄で保存すると「店舗名へ、ようこそ。」に戻ります。 |
| 通知音 | 「この端末の通知音」で端末ごとに設定します。 |

タップ回数を変更したら、「確定済みのタップ回数」を確認してください。タップ間隔が1秒以上空くと途中の回数がリセットされます。パスワード確認は引き続き必要で、入口画面へ戻る操作は1回です。

## 入口端末の交代と復旧

### 今の入口が動いている場合

1. 新しい入口にする端末でスタッフログインし、「入口端末の交代・復旧」の見出しを開きます。
2. 端末の呼び名を入力し、「この端末を交代先として登録」を押します。
3. 今の入口では受付を止め、全端末の送信・未確定操作がなくなるまで待ちます。
4. 今の入口で交代先を選び、呼び名と識別番号の末尾を照合します。
5. 「選んだ端末へ入口を交代」を押し、スタッフ用パスワードで確認します。
6. 新しい入口に「この端末が入口・確定端末」と表示されたことを確認して受付を再開します。

同じ台帳内の交代なので、バックアップの読み込みは不要です。旧入口はスタッフ端末として利用できます。

### 旧入口が使えない場合

旧入口のアプリを終了し、可能なら端末の電源も切ります。新しい入口にする端末で共有履歴を受信し、スタッフ画面から「旧入口が使えないため、この端末で復旧」を選びます。実際の席・受付と画面を照合し、確認欄とパスワードで実行してください。

復旧対象は、その端末が**受信済みの履歴まで**です。通信できない旧入口を遠隔停止することはできません。旧入口と新入口の両方で受付しないでください。

## バックアップと版をまたぐ移行

1. 受付を止め、全端末の送受信と未確定操作を確認します。
2. 旧台帳のスタッフ画面で「バックアップ・版をまたぐ引き継ぎ」を開き、「引き継ぎファイルを保存」を押します。
3. Delta Chatでファイル付き下書きが開いたら、スタッフ専用グループか自分用チャットに送って保存します。ファイルが残っていることを確認してください。
4. 旧台帳を全端末で終了し、新しい版のアプリをグループへ1回だけ送ります。
5. 新しい空の台帳でスタッフログインし、**入口を指定する前に**引き継ぎファイルを読み込みます。
6. 店舗名・保存日時・件数を確認し、バックアップ側のスタッフ用パスワードで実行します。
7. 送受信確認後、引き継いだパスワードでログインし、新しい入口を指定します。
8. 全端末が新しい同じ添付メッセージを開き、受付番号・席番号と共有動作を確認して再開します。

受付番号、氏名、人数、日時、席、待ち順、案内状態、退店・取消履歴、店舗設定、タップ回数、パスワード設定、未確定操作を保持します。入口指定・端末の呼び名・通知音は移行先で設定し直します。

- 共通データ形式は `seatmate-backup` の `schemaVersion: 1`。同形式に対応する版の間で引き継げます。
- 1.1.0から移行できます。回数設定を含まないバックアップではタップ回数は3回になります。
- **1.0.4以前には書き出し機能がないため、旧版の既存データを自動移行できません。** 受付・利用席がない時点で切り替え、店舗設定などを再設定します。
- 使用中の台帳への上書き・合併、別台帳間の自動共有、自動バックアップは行いません。
- 保存後の操作はファイルに含まれません。上限は8MiB、確定履歴と未確定操作の合計30,000件です。
- 破損したファイルや未対応の形式は適用しません。将来の新形式には対応する読み込み機能が必要です。

## 共有されないとき

1. 全端末が、同じグループの同じ添付メッセージを開いているか確認します。
2. 指定した入口端末で、アプリを開いたままにします。
3. Delta Chatで通常のメッセージを送受信できるか確認します。
4. 「入口確認待ち」「送信・受信確認待ち」の件数を確認します。
5. 必要なら「未確認の送信を再試行」を押して待ちます。再登録する前に重複受付がないか確認します。

入口のアプリが閉じている間は、スタッフの操作が確定しません。案内が見えない場合は、入口がスタッフ画面になっていないかも確認してください。

## 利用上の注意と検証状況

- 信頼できるスタッフ専用グループで使います。パスワードは画面切替用の簡易ロックです。
- 名前は任意です。店舗対応に必要な情報だけ登録してください。
- バックアップは暗号化されず、氏名やパスワードのハッシュを含みます。お客様のいるグループや公開の場所へ送らないでください。
- 待ち時間は手動の目安であり、自動計算やカウントダウンではありません。
- 席は番号で管理します。連席やテーブル単位の制約は自動判定しません。
